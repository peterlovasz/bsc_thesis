# Machine Learning-Based Respiration Sensing with 28 GHz ISAC CSI

This repository contains the code used for the thesis:

**Machine Learning-Based Respiration Sensing with 28 GHz ISAC System Under Different Orientations**

## Contents

- `classification/`: breathing/non-breathing classification scripts
- `regression/`: respiration waveform reconstruction scripts

## Data availability

The raw measurement dataset is not included in this repository due to file size.
